In Code Tutor → Analyze code → Explain, use beginner-friendly, simple language, make the answer easy to scan, and visually highlight the most important code.

**Why:** the user said the current explanations are hard to understand and asked for clearer teaching with visual emphasis.

**How to apply:** Prefer short plain-language explanations, define technical terms, and highlight a small number of key line ranges rather than treating every line as equally important.
